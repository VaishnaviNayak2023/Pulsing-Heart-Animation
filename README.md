# 💖 Pulsing Heart Animation

A visually stunning, interactive pulsing heart animation inspired by the drama *Lighter and the Princess*. Perfect for learning HTML, CSS, and JavaScript animations.

This project recreates the iconic scene where **Li Xun** makes a heart in coding class, combining neon particle effects and a soft CSS heart with a toggleable heartbeat.

---

## 🌟 Features

### Heart on Canvas (`heart.html`)

* Neon pink and red particle heart
* Smooth particle motion and pulsing animation
* Responsive to window resizing

### CSS Heart (`style1.css` + `script.js`)

* Soft pink heart using `clip-path`
* Pulse animation using CSS `@keyframes`
* Toggle heartbeat animation with a button
* Light pink background with soft purple text

---

## 🛠️ Installation

1. Clone this repository:

```bash
git clone https://github.com/VaishnaviNayak2023/Mini-Projects.git
```

2. Open `heart.html` in a browser to view the particle heart.
3. Open the HTML file that uses `style1.css` and `script.js` to see the CSS heart.

---

## 🎮 Usage

### CSS Heart

* Click the "Toggle Heartbeat" button to start or stop the heartbeat animation.

### Particle Heart

* Animates automatically.
* Resize the window to see the canvas adapt dynamically.
